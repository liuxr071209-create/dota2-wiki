关于本站

一个为 7.41f 版本准备的中文 Dota 2 图鉴。目标很简单：把英雄、技能、物品和版本数据放在同一个安静、快速、可离线部署的页面里。

这个站有什么

英雄页包含 1 级基础属性、技能逐级数值、神杖与魔晶升级、10/15/20/25 级天赋、近期胜率与七日走势、分阶段出装热度和克制关系。物品页包含价格、分类、主动与被动效果、具体数值、合成组件、后续升级，以及近期最常出这件装备的英雄。

英雄的“常见位置”是编辑整理，用于图鉴筛选和快速理解，不是赛事位置统计。真正带样本的统计只有胜率、登场率、出装和克制，它们全部来自 OpenDota。

版本与数据口径

  • 数值：Valve 官方 Dota 2 数据接口（英雄、技能、物品、天赋），数据版本 7.41f。
  • 胜率 / 登场率：OpenDota heroStats，公开对局样本约 383 万场。登场率按“每场出现率”计算，因此所有英雄相加约为 1000%。
  • 走势：OpenDota 最近七个统计窗口的胜率，末位窗口可能尚未完整，低样本英雄的折线波动会比较大。
  • 出装：OpenDota itemPopularity 的出门 / 前期 / 中期 / 后期四阶段，按该阶段最高选取次数归一化为热度条。
  • 克制：OpenDota matchups，只保留至少 25 场对局的英雄；样本较小时请谨慎解读。
  • 补丁说明：Valve 官方 7.41f 更新页，中文文本参考官方中文与社区整理，按官方条目校对。

为什么是静态站

整站没有后端、没有数据库、没有构建步骤。HTML、CSS、JSON 和图片就是全部内容，直接放到 GitHub Pages、Cloudflare Pages 或任意静态服务器即可。所有路径都是相对路径，仓库放在子路径下也能正常打开。

重新抓取数据只需要 Node.js 20+：npm run data。脚本会从 Valve 数据接口、OpenDota 与 Steam CDN 拉取并重新生成 data/，然后下载素材到 assets/。

发现数值错误、图片缺失或翻译问题，欢迎在仓库提交 issue。版本更新后，维护者只需要重新运行数据脚本并检查差异。

GitHub Pages

仓库根目录已经包含 .nojekyll 与 Pages 工作流。推送到 main 后，在仓库 Settings → Pages 选择 GitHub Actions，工作流会发布整站。也可以直接把仓库设为 “Deploy from a branch” 的根目录。

不要用 file:// 直接打开 HTML，浏览器会拦截 JSON 读取。本地预览请运行 npm run serve，然后访问终端输出的地址。
